Order state (2026-10-09): JLC order for both boards + both stencils placed (hand assembly, no JLC assembly). JLC engineering asked about the mainboard edge half-holes for the button/buzzer springs; Answered **Option 2: keep the outline exactly as designed, no castellation**, accepting that the barrel copper of the LIGHT, MODE and ALARM holes may tear when the edge is routed (the pads are only spring contacts; Sensor Watch's production gerbers have the same 3 mm plated holes with no castellation note). On arrival, deburr those three edges and check each button pad for shorts to GND and VDD. The cart lists the mainboard finish as OSP; it should be ENIG for the LCD, battery and spring contacts.

Not included: **Sensor Watch BLE flex rev B** (ANNA-B112 BLE module on a flex for a stock Sensor Watch). It is unfinished and lives in `pcb-layout/flex-revB-ble/` in the project files.
